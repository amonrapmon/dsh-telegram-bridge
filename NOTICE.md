# Attribution and design references

This project implements an independent Telegram transport plugin for DeepSeek
Harness with topic-aware routing and the public DSH 0.2.0-rc.2 interfaces.

The architecture and behavior were studied alongside these open-source projects:

- https://github.com/todayer/todayer-dsh-telegram-bridge
  License: MIT, copyright © 2026 dsh-telegram-channel contributors.
- https://github.com/hi-wenw/dsh-telegram-channel
  License: MIT (see upstream repository).
- https://github.com/IgnatAi401/dsh-telegram
  License: BSD-3-Clause (consult upstream for attribution terms).
- https://github.com/deepseek-ai/deepseek-harness
  The host API and extension reference.

No source files from those projects have been copied wholesale into this
repository. The original licenses of all referenced projects remain with their
respective authors. This project is not an official DeepSeek AI extension.
